# Quick brief — growrix-home-v2

- **Offer:** Growrix OS homepage, founder-led, three service pillars: Develop, Automate, Grow.
- **Audience:** owners and buyers of websites, apps and AI automation (law firms are a niche for depth pages, not the homepage).
- **Mood:** calm, precise, accountable. Warm off-white, near-black ink, one orange accent for interactive elements only (research tokens).
- **Hero:** pinned, scroll-driven, three slides in order Develop → Automate → Grow. Fixed founder H1 stays on screen. CSS only, no motion library.
- **Sections:** header with mega menu · pinned hero · founder strip · recent work (labelled) · how I work · niche row (law firms) · FAQ · final CTA · footer.
- **Motion intensity:** 2 of 3 (cinematic hero only; everything else static or a short fade).
- **Source:** `docs/revised-website-plan/03-homepage-hero.md` and `02-sitemap-and-menu.md`. Plan, not a creative brief from site-planner.
